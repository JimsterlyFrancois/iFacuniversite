# Documentation iFac Université

Cette documentation est destinée aux administrateurs de la plateforme, aux responsables universitaires, aux équipes techniques et aux utilisateurs qui souhaitent comprendre le produit.

- [Guide complet d’iFac Université](GUIDE_COMPLET_IFAC_UNIVERSITE.md) — vision, importance, publics, hiérarchie, rôles, permissions, parcours de bout en bout, documents, communications, architecture, sécurité, mobile et limites actuelles.

- [Espaces et modèle de permissions](SIX_ROLE_WORKSPACES.md) — document de conception et historique des six espaces.
- [Annonces de plateforme](PLATFORM_ANNOUNCEMENTS.md) — audiences, ciblage, affichage et gestion des responsables.

## Règle de lecture

Le Guide complet est le point d’entrée fonctionnel. Les guides spécialisés donnent davantage de détails sur un aspect particulier. Les documents historiques doivent être lus avec leur date et leur état d’implémentation ; le code, la configuration de production et les tests de la version actuelle restent les références du comportement effectif.
